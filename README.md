
# Portafolio de Evidencias - Programación Orientada a Objetos

## Sistema de Gestión de Pedidos - Sabores de Heredia

Proyecto académico de Universidad CENFOTEC desarrollado en Java.

## Objetivo

Aplicar los principios fundamentales de Programación Orientada
a Objetos mediante un sistema de gestión de pedidos para restaurante.

## Funcionalidades

- Registrar productos.
- Registrar mesas.
- Crear pedidos.
- Agregar productos y cantidades.
- Calcular subtotales y totales.
- Mostrar recibos.
- Liberar mesas.

## Clases Java

- Main
- Restaurante
- Producto
- Mesa
- Pedido
- DetallePedido
- ImpresoraRecibos

## Conceptos aplicados

- Abstracción: modelado de entidades del restaurante.
- Encapsulamiento: atributos privados y métodos públicos.
- Modularidad: responsabilidades separadas por clases.
- Agregación: Restaurante con Producto, Mesa y Pedido.
- Composición: Pedido con DetallePedido.
- Asociación: Pedido con Mesa y DetallePedido con Producto.
- Dependencia: Restaurante utiliza ImpresoraRecibos.

## Ejecución

1. Abrir el proyecto en IntelliJ IDEA.
2. Verificar la configuración del JDK.
3. Abrir src/Main.java.
4. Ejecutar el método main.

## Resultados esperados

- Pedido 101: CRC 8200.
- Pedido 102: CRC 4000.
- Mesa 1 liberada al finalizar.
